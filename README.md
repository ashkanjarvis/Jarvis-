# پروژه Jarvis برای اندروید

## این پروژه چه کاری انجام می‌دهد؟

- یک سرویس پس‌زمینه (Foreground Service) که مدام به میکروفون گوش می‌دهد.
- وقتی بگویی **"جارویس"** (یا Jarvis)، یک دایره‌ی آبی‌رنگ متحرک و چرخان بالای صفحه —
  روی هر برنامه‌ای که باز باشد — ظاهر می‌شود (`OverlayService.kt`).
- بعد از ظاهر شدن، به دستور بعدی‌ات گوش می‌دهد. مثلاً:
  - «جارویس اینستاگرام رو باز کن» → اینستاگرام باز می‌شود.
  - «جارویس تلگرام رو باز کن» → تلگرام باز می‌شود.
  - هر برنامه‌ی دیگری که روی گوشی نصب باشد هم قابل جستجو و باز کردن است
    (`AppLauncher.kt` هم اسم‌های معروف فارسی/انگلیسی را می‌شناسد، هم بین
    اسم نمایشی تمام اپ‌های نصب‌شده جستجو می‌کند).
- جارویس با صدا (Text-to-Speech) جواب می‌دهد.

## بخش هوش مصنوعی (پاسخ به هر سوالی، مخصوصاً تنظیمات گیمینگ)

جارویس حالا برای هر چیزی که محلی نتواند جواب بدهد (یعنی هر چیزی جز «باز کردن یک اپ»)،
از یک مدل هوش مصنوعی رایگان (Gemini گوگل) استفاده می‌کند — اما همیشه با شخصیت
و لحن «جارویس» جواب می‌دهد. این مدل به‌طور خاص برای موارد زیر تنظیم شده:

- سوالات عمومی، علمی، فنی، برنامه‌نویسی و غیره
- **تنظیمات گیمینگ**: سنسیتیویتی موس و DPI، کیبایند، کانفیگ‌های بازی‌های رقابتی
  (مثل CS2، Valorant، PUBG، فورتنایت)، تنظیمات گرافیکی برای فریم‌ریت یا کیفیت بهتر،
  و توصیه‌ی سخت‌افزار/مانیتور

### گرفتن کلید رایگان (کاملاً رایگان است)

1. برو به [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. با اکانت گوگلت وارد شو.
3. روی «Create API key» بزن و کلید را کپی کن.
4. داخل اپ جارویس، کلید را در کادر مربوطه بچسبان و «ذخیره‌ی کلید» را بزن.

⚠️ نسخه‌ی رایگان محدودیت تعداد درخواست در دقیقه/روز دارد (برای استفاده‌ی شخصی
کافی است). کلید فقط روی خود گوشی ذخیره می‌شود و جایی ارسال نمی‌شود مگر مستقیم
به سرور گوگل برای گرفتن جواب.

## چه چیزی هنوز ساخته نشده (و باید صادقانه بگویم چرا)

1. **تشخیص دست با دوربین** (مشت=جمع شدن، دست باز=گسترش):
   این نیاز به کتابخانه‌ی تشخیص لمسه‌ی دست (مثل MediaPipe Hands یا ML Kit)
   دارد که پیاده‌سازی کامل و پایدارش چند روز کار جدا می‌طلبد. اسکلت این
   پروژه به‌گونه‌ای نوشته شده که بعداً بتوانی یک کلاس `HandGestureDetector`
   اضافه کنی که تابع `showOverlay()` / `hideOverlay()` را در `OverlayService`
   صدا بزند — این دو تابع همین الان آماده‌اند.

2. **کلمه‌ی فعال‌ساز واقعیِ آفلاین و دائمی** (مثل "Hey Siri"):
   اندروید به‌صورت پیش‌فرض چنین قابلیتی ندارد. این پروژه از
   `SpeechRecognizer` استفاده می‌کند که هر چند ثانیه یک بار گوش می‌دهد
   و دوباره شروع می‌کند — یعنی نزدیک به همان تجربه است، ولی صد در صد
   شبیه یک موتور اختصاصی wake-word (مثل Picovoice Porcupine) نیست.
   برای دقت بهتر می‌توانی بعداً Porcupine را اضافه کنی.

3. **هوش مصنوعی مکالمه‌ای واقعی** (پاسخ به هر سوالی مثل فیلم):
   فعلاً فقط دستور «باز کردن برنامه» را می‌فهمد. برای مکالمه‌ی هوشمند
   باید متن تشخیص داده شده را به یک API هوش مصنوعی (مثل Claude) بفرستی؛
   جای این کار در فایل `CommandProcessor.kt` مشخص شده.

## چرا این‌ها را همین الان اضافه نکردم؟

چون خواستی «هیچ‌چیز جا نیفتد»، اما پیاده‌سازی کامل تشخیص دست با دوربین
یا یک موتور wake-word اختصاصی، به‌تنهایی معادل چند هفته توسعه‌ی حرفه‌ای
است و بدون تست روی گوشی واقعی امکان تضمین درستی‌اش نیست. پروژه‌ای که
الان داری کاملاً واقعی و قابل نصب است؛ بخش‌های پیشرفته‌تر را می‌شود
به‌مرور روی همین پایه اضافه کرد.

## ساخت APK — روش پیشنهادی (مطمئن‌ترین راه)

1. [Android Studio](https://developer.android.com/studio) را روی کامپیوتر نصب کن.
2. این پوشه (`JarvisApp`) را با گزینه‌ی **Open** در Android Studio باز کن.
3. صبر کن Gradle sync تمام شود (نیاز به اینترنت دارد تا کتابخانه‌ها دانلود شوند).
4. از منو: `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
5. فایل APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.
6. آن را به گوشی منتقل کن و نصب کن (باید اجازه‌ی «نصب از منابع ناشناس» را بدهی).

## ساخت APK داخل Termux (روش جایگزین — پیچیده‌تر و ناپایدارتر)

⚠️ ساخت پروژه‌های اندرویدی داخل Termux به دلیل نیاز به Android SDK و حجم بالای
حافظه/پردازش، روی خیلی از گوشی‌ها کند است یا با خطا مواجه می‌شود. اگر با مشکل
مواجه شدی، روش بالا (Android Studio) را امتحان کن.

```bash
pkg update && pkg upgrade
pkg install openjdk-17 gradle git wget -y

# نصب Android command-line tools (نیاز به دانلود دستی از سایت گوگل دارد)
mkdir -p ~/android-sdk/cmdline-tools
cd ~/android-sdk/cmdline-tools
wget https://dl.google.com/android/repository/commandlinetools-linux-XXXX_latest.zip
unzip commandlinetools-linux-XXXX_latest.zip
mv cmdline-tools latest

export ANDROID_HOME=~/android-sdk
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools

yes | sdkmanager --licenses
sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"

# برو داخل پوشه‌ی پروژه (که همین فایل را از آن دریافت کردی)
cd /path/to/JarvisApp
gradle assembleDebug

# فایل خروجی:
# app/build/outputs/apk/debug/app-debug.apk
```

نکته: شماره نسخه‌ی `commandlinetools-linux-XXXX_latest.zip` را باید از
صفحه‌ی رسمی [developer.android.com/studio#command-tools](https://developer.android.com/studio#command-tools)
بگیری، چون مرتب آپدیت می‌شود.

## اولین اجرا روی گوشی

1. اپ را باز کن.
2. دکمه‌ی «اجازه‌ی نمایش روی سایر برنامه‌ها را بده» را بزن و اجازه بده.
3. دکمه‌ی «اجازه‌ی دسترسی به میکروفون را بده» را بزن و اجازه بده.
4. دکمه‌ی «فعال‌سازی جارویس» را بزن.
5. بگو: **«جارویس»** — دایره‌ی آبی چرخان بالای صفحه ظاهر می‌شود.
6. بعد بگو مثلاً: **«اینستاگرام رو باز کن»**.

## افزودن دستورهای جدید در آینده

فقط کافی‌ست داخل `CommandProcessor.kt` یک شرط `if` جدید اضافه کنی؛
مثلاً برای «جارویس چراغ‌قوه رو روشن کن» یا «جارویس موزیک پخش کن».
معماری پروژه به‌گونه‌ای است که این کار به بقیه‌ی بخش‌ها آسیبی نمی‌زند.
